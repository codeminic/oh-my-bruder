# Idea: an interactive IoT and cloud scene for the software era

## The idea

For the software part ("Building software"), I want something more interactive. It should show devices that are
connected to the cloud over IoT, and the things running in the cloud.

We need a way to visualize that which looks really cool and is also a little bit interactive.

## Where it fits

- It's for the software era (`#era-software`). Today that era's toy is the live code toy in `src/toys/code`.
- Each era has one toy (see AGENTS.md), so this would replace the code toy or build on it.
